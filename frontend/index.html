Multi-Node LangGraph
NODE 1 • MULTIMODAL
Document Extractor

PyMuPDF rendering + Gemini Vision cascade dengan validasi Pydantic strict JSON.

NODE 2 • HYBRID RAG
Qdrant RRF Retriever

Menggabungkan Dense Multilingual Embedding + Sparse BM25 untuk akurasi kode & nominal.

NODE 3 • REASONING
Compliance Auditor

Groq gpt-oss-120b mengevaluasi kalkulasi pajak, plafon biaya, dan kelengkapan otorisasi.

NODE 4 • REFLECTION
Deterministic & LLM Critic

Mencegah halusinasi sitasi rule_code dan memicu re-retrieval otomatis jika ada aturan terlewat.

Production Guardrails & Observability

  • Multi-Provider Resilience: Otomatis melakukan failover lintas model Gemini dan Groq saat terjadi kuota limit atau timeout.
  • Citation Grounding Check: Verifikasi deterministik memastikan setiap rule_code pada putusan benar-benar berasal dari hasil retrieval Qdrant.
  • Langfuse Telemetry: Setiap eksekusi agen tercatat latensi, token, dan jejak pemanggilannya di Langfuse Cloud.
  • API Rate Limiting: Proteksi SlowAPI per alamat IP dan pembatasan ukuran file maksimal 5 MB.
